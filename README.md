# Pomodoro Timer

A Pomodoro focus timer in plain HTML, CSS and JavaScript. Work in 25-minute
focus sessions, take 5-minute short breaks, and a 15-minute long break after
every 4 sessions. A beep plays when a session ends.

## Features

- Focus (25 min), short break (5 min) and long break (15 min) modes
- Automatic mode switching with session counter
- Beep via the Web Audio API — no audio files needed
- Live countdown in the browser tab title

## How to run

Just open `index.html` in your browser. No build step, no dependencies.
